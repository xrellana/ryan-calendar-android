# 工作日程 Android 原生客户端（Kotlin + Jetpack Compose）

本目录为「工作日程（云端多账号版）」的原生 Android 客户端，直接对接已部署的 Node.js / Express 云端后端，**无需修改或重新部署现有服务端**即可与 Web 端实时双向同步。

## 核心功能

- **零改动对接现有云端服务**：支持自定义输入服务器地址（HTTPS 或局域网 HTTP），通过 OkHttp 持久化 `CookieJar` 保存 `workcal_sid` 30 天滑动会话 Cookie，并自动附加 `X-Requested-With: WorkCal` 防护头。
- **4 Tab 底部导航结构**：
  1. **日程**：支持左右滑动切换的月 / 周 / 年三视图；内置中国农历、二十四节气、法定节假日「休/班」角标与月视图跨天围合泳道；选中日期下方直接展示当日日程列表，右下角悬浮按钮（`+`）一键新建日程；支持顶栏搜索与多选类别筛选。
  2. **近期**：支持切换「今起 7 天 / 今起 1 个月」待办行程时间线与下拉同步。
  3. **统计**：支持按月 / 按年统计总日程数、跨天项目数、有日程天数与各类别分布进度条。
  4. **我的**：账号信息与手动同步、**本地每日定时通知**（支持自定义提醒时间、Android 13+ 通知权限申请、开机自动恢复调度与一键发送测试通知）、类别管理与优先级排序、个人 `.ics` 日历订阅复制与重置、修改显示名称与密码、退出登录。
- **本地缓存与自动同步**：基于 Room 缓存最近一次拉取的类别、日程与节假日数据，打开 App 秒开缓存，切回前台自动静默与云端同步。
- **定位聚焦**：管理员后台与 Excel 台账批量导入保留在 Web 端使用，移动端专注于查看、增删改查、搜索与提醒。

## 构建与运行

1. 使用 **Android Studio Ladybug（2024.2）或更新版本** 打开 `android/` 目录（需要 **JDK 17** 与 **Android SDK 35**）。
2. 等待 Gradle Sync 完成（首次同步会下载 Gradle 8.9 与依赖包）。
3. 连接 Android 8.0（API 26）及以上真机或模拟器，点击 **Run** 即可安装调试；或执行：
   ```bash
   ./gradlew assembleDebug
   ```
   生成的 APK 位于 `app/build/outputs/apk/debug/app-debug.apk`。
4. 首次打开 App 时，在登录页填写您已部署的云端服务地址（例如 `https://cal.example.com`）与账号密码即可开始同步。
