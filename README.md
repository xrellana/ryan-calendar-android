# 工作日程（Android 原生客户端）

「工作日程（云端多账号版）」的原生 Android 客户端，基于 **Kotlin + Jetpack Compose + Material 3** 构建，直接对接已部署的云端日程服务端，实现手机端与 Web 端实时双向同步。

## 下载安装

前往本仓库右侧 **[Releases](../../releases)** 页面，下载最新版本的 `ryan-calendar-v*.apk`（已签名压缩正式版），传输到 Android 8.0+ 手机安装即可。

## 核心特性

- **零改动对接云端后端**：直连云端服务（`https://calendar.meowoo.net`），通过持久化 `CookieJar` 兼容 30 天滑动会话并自动附加 CSRF 防护头，与 Web 端实时同步。
- **5 Tab 移动端原生交互**：
  - **日程**：支持左右手势滑动切换的月 / 周 / 年三视图；内置 1900–2100 中国农历、二十四节气、法定节假日「休/班」角标与月视图跨天围合泳道；选中日期下方直接联动展示当日日程，右下角悬浮按钮（`+`）一键新建日程；支持全局搜索与类别多选筛选。
  - **评估**：评估项目管理，分「项目 / 费用 / 天数 / 差旅」四个子页，可左右滑动切换。项目卡片默认合并同名项目的预评估与正式评估，可在卡片上直接改项目状态和费用状态，长按进入多选后批量修改；费用统计和天数统计带月度柱状图与分组下钻；差旅支持「近期项目」一键带出等级与评估计划，「保存并再记一笔」连续录入，同一天有多笔差旅时可按住右侧手柄拖动调整先后（与 Web 端共用同一份顺序）。新建、修改、删除评估项目会自动同步工作日程，日程里的「外出评估」条目也会直接打开对应项目。
  - **近期**：今起 7 天 / 今起 1 个月待办时间线，支持下拉刷新同步。
  - **统计**：按月 / 按年统计总日程数、跨天项目数、有日程天数与各类别分布进度条。
  - **我的**：账号信息与手动同步、**本地每日定时通知**（自定义提醒时间、开机自恢复、一键测试通知）、类别管理与优先级排序、个人 `.ics` 订阅链接复制/重置、改昵称、改密码与退出登录。
- **离线缓存 + 前台自动同步**：Room 本地数据库缓存最近同步的日程与节假日，打开秒显数据，切回前台自动静默同步云端最新变更。
- **清晰分工**：管理员后台、Excel 导入导出与评估规则/费率设置保留在 Web 端，Android App 专注日常浏览、增删改查、搜索与提醒。

## 发布新版正式 APK（GitHub Actions）

本仓库已配置正式签名与自动发版流水线（`.github/workflows/android-release.yml`），无需在本地安装 Android Studio：

- **方式一（推荐）**：推送语义化版本标签即可自动编译签名并发布到 GitHub Releases：
  ```bash
  git tag v1.0.1
  git push origin v1.0.1
  ```
- **方式二**：在 GitHub 仓库 **Actions → Release Android APK → Run workflow** 中填写版本号手动触发。

> 签名密钥通过 GitHub Repository Secrets（`KEYSTORE_BASE64`、`KEYSTORE_PASSWORD`、`KEY_ALIAS`、`KEY_PASSWORD`）注入，确保每次发版使用同一签名证书，手机端可直接覆盖升级安装不丢本地配置。

## 本地开发（可选）

如需在本地调试，可使用 Android Studio Ladybug（2024.2+，JDK 17 + Android SDK 35）直接打开本仓库根目录，或执行：

```bash
gradle testDebugUnitTest
gradle assembleDebug
```
